# Archivist - Client

This is the React frontend for the Archivist D&D 5e character sheet application.

For complete project information, setup instructions, and documentation, please refer to the [root README](../README.md).

## Client-Specific Information

This client was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

### Development

To run only the client in development mode:

```
npm start
```

This will start the development server at [http://localhost:3000](http://localhost:3000).

### Testing

```
npm test
```

Launches the test runner in interactive watch mode.

### Building

```
npm run build
```

Builds the app for production to the `build` folder, optimized for performance.
